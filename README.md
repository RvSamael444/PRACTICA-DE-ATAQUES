# Práctica 1: Análisis de Registros de Ataques
**Materia:** Introducción a la Ingeniería de Software
**Institución:** UACM

Este programa en C procesa un registro simplificado de accesos a un servidor para detectar comportamientos sospechosos (posibles ataques de fuerza bruta). Implementa arreglos, paso de parámetros por valor/referencia y apuntadores para clasificar eventos por equipo.

## Compilación y Ejecución
1. Abre tu terminal en la carpeta del proyecto.
2. Compila el código ejecutando: `gcc PROYECTO.c -o practica`
3. Ejecuta el programa con: `.\practica.exe`
